## Neu

- **Autorenseiten chronologisch:** Die Bücher einer Autorin oder eines Autors stehen jetzt standardmäßig in der Reihenfolge ihres Erscheinungsjahres – das älteste Buch zuerst. Bücher ohne Jahresangabe stehen am Ende.
- **Sortieren auf der Autorenseite:** Über das Sortiermenü lassen sich alternativ Titel, Hinzufügedatum und Länge wählen; ein erneuter Klick auf die aktive Option dreht die Richtung.
- **Kachel oder Liste:** Die Ansicht lässt sich auf der Autorenseite genauso umschalten wie in der Bücherübersicht. Die gewählte Darstellung gilt für beide Seiten.

## Installation

### Windows

`Navideck-Setup-1.14.0.exe` starten und über die bisherige Version installieren. Server und Sitzung bleiben erhalten. Der Installer ist nicht signiert; Windows SmartScreen fragt einmal nach: **Weitere Informationen → Trotzdem ausführen**.

### Linux / Bazzite

1. `Navideck-1.14.0-x86_64.AppImage` herunterladen.
2. Datei als ausführbar markieren (Rechtsklick → Eigenschaften, oder `chmod +x Navideck-*.AppImage`).
3. Per Doppelklick starten. Unter Bazzite lässt sie sich optional über **Startmenü → Rechtsklick → Zum Startmenü hinzufügen** anheften.

Die AppImage bringt Electron mit und braucht keine Systeminstallation. Falls Bazzite die Ausführung blockiert, hilft `./Navideck-1.14.0-x86_64.AppImage --appimage-extract-and-run`.
