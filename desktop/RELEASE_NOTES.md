## Neu

- **Einheitliches Sortieren:** Auf allen Listen – Alben, Bücher, Sendungen und Episoden – steht links die Überschrift, rechts daneben ein **Sortier-Knopf**. Erst beim Antippen öffnet sich die Auswahl der Sortierungen (und der Richtung); daneben bleibt wie gewohnt die Ansichtswahl. Die Kopfzeile bleibt dadurch auch auf dem Handy einzeilig, statt mit einer Chip-Reihe umzubrechen.

## Installation

### Windows

`Navideck-Setup-1.7.0.exe` starten und über die bisherige Version installieren. Server und Sitzung bleiben erhalten. Der Installer ist nicht signiert; Windows SmartScreen fragt einmal nach: **Weitere Informationen → Trotzdem ausführen**.

### Linux / Bazzite

1. `Navideck-1.7.0-x86_64.AppImage` herunterladen.
2. Datei als ausführbar markieren (Rechtsklick → Eigenschaften, oder `chmod +x Navideck-*.AppImage`).
3. Per Doppelklick starten. Unter Bazzite lässt sie sich optional über **Startmenü → Rechtsklick → Zum Startmenü hinzufügen** anheften.

Die AppImage bringt Electron mit und braucht keine Systeminstallation. Falls Bazzite die Ausführung blockiert, hilft `./Navideck-1.7.0-x86_64.AppImage --appimage-extract-and-run`.
