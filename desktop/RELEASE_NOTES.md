## Neu

- **Episodenseite:** Ein Klick auf eine Podcast-Folge öffnet jetzt eine eigene Seite mit Titel, Sendedatum, Dauer, Show notes und der Möglichkeit, die Folge direkt abzuspielen oder in die Warteschlange zu legen.
- **Wiedergabe aus der Liste:** Das Play-Symbol rechts an einer Folge startet sie sofort – oder setzt an der gemerkten Stelle fort, wenn schon angefangen wurde.
- **Aufgeräumte Folgenlisten:** Das Mikrofon-Symbol ohne Funktion ist entfernt. Die ganze Zeile führt jetzt zur Episodenseite.

## Installation

### Windows

`Navideck-Setup-1.17.0.exe` starten und über die bisherige Version installieren. Server und Sitzung bleiben erhalten. Der Installer ist nicht signiert; Windows SmartScreen fragt einmal nach: **Weitere Informationen → Trotzdem ausführen**.

### Linux / Bazzite

1. `Navideck-1.17.0-x86_64.AppImage` herunterladen.
2. Datei als ausführbar markieren (Rechtsklick → Eigenschaften, oder `chmod +x Navideck-*.AppImage`).
3. Per Doppelklick starten. Unter Bazzite lässt sie sich optional über **Startmenü → Rechtsklick → Zum Startmenü hinzufügen** anheften.

Die AppImage bringt Electron mit und braucht keine Systeminstallation. Falls Bazzite die Ausführung blockiert, hilft `./Navideck-1.17.0-x86_64.AppImage --appimage-extract-and-run`.
