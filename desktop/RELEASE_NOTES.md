## Neu

- **Ladeanzeige in den Play-Buttons:** Während ein Titel (vor allem ein Hörbuch) geladen wird, zeigt der Play-Knopf jetzt ein sich drehendes Rädchen statt des Play-Symbols – auf der Detailseite, auf den Karten, in der Player-Leiste und in der Vollansicht. Man sieht sofort, dass der Inhalt noch lädt, statt auf einen scheinbar toten Knopf zu starren.

## Installation

### Windows

`Navideck-Setup-1.12.2.exe` starten und über die bisherige Version installieren. Server und Sitzung bleiben erhalten. Der Installer ist nicht signiert; Windows SmartScreen fragt einmal nach: **Weitere Informationen → Trotzdem ausführen**.

### Linux / Bazzite

1. `Navideck-1.12.2-x86_64.AppImage` herunterladen.
2. Datei als ausführbar markieren (Rechtsklick → Eigenschaften, oder `chmod +x Navideck-*.AppImage`).
3. Per Doppelklick starten. Unter Bazzite lässt sie sich optional über **Startmenü → Rechtsklick → Zum Startmenü hinzufügen** anheften.

Die AppImage bringt Electron mit und braucht keine Systeminstallation. Falls Bazzite die Ausführung blockiert, hilft `./Navideck-1.12.2-x86_64.AppImage --appimage-extract-and-run`.
